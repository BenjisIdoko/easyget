# EasyGet UI Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the whole EasyGet storefront to a mobile-first, photo-led app look (A's flow, B's light look) in the existing brand colors, with free stock photos.

**Architecture:** Keep the Next.js app, routes, cart context and API routes untouched. Replace design tokens in `globals.css`, add a `ProductImage` component and a mobile `BottomNav`, and rebuild the navbar, product card, home, product, cart and form pages on top of them. Products gain an optional `imageUrl` (Unsplash, linked not downloaded).

**Tech Stack:** Next.js 16.4 (App Router, Turbopack, `cacheComponents`), React 19, Tailwind v4, lucide-react, `next/image`.

**Spec:** `docs/superpowers/specs/2026-11-13-ui-revamp-design.md`

**Testing note:** the repo has no test runner and this is visual work, so each task is verified with `npx tsc --noEmit`, `npm run lint`, and a visual check in the browser at 375px and 1280px instead of unit tests. Do not add a test framework. Read `node_modules/next/dist/docs/` before using any Next API you are unsure of (AGENTS.md).

## Global Constraints

- Brand colors stay: `--brand` #6d28d9 (primary accent), `--pharmacy` #0f766e (pharmacy items), `--food` #d97706 (food items). No lime, no dark mode.
- Fonts stay Sora (display) + Plus Jakarta Sans (body), loaded by the existing stylesheet `<link>` in `layout.tsx` (its comment documents why `next/font` is avoided; do not switch).
- Black pill buttons/nav use `#111` (`--ink`); background is a soft violet-tinted-to-white wash.
- No functional text under 11px; check contrast of text on brand/pharmacy/food chips.
- Do not change `cart-context.tsx`, `src/app/api/**`, `supabase/**`, routes, or the `Product` fields other than adding `imageUrl?`.
- Layout is mobile-first: bottom nav below `md`, top bar from `md` up; grids widen on desktop.
- Pharmacy must stay credible: keep the "Prescription required" flag visible on cards and product page.
- Photos are generic (not a specific branded medicine); keep emoji as fallback.

## Review Focus

- Image fails to load or product has no `imageUrl` → emoji fallback on the pastel backdrop, no broken-image icon.
- Long product names (e.g. "Acycor Plus (Aceclofenac & Paracetamol)") wrap/clamp without breaking card or cart-row layout at 375px.
- Search with no matches → clear "nothing found" state, not a blank grid.
- Empty cart and Paystack-not-configured pages still render as designed pages.
- Fixed bottom nav and the product page's sticky Add to Cart bar never overlap each other or hide the footer/last content (bottom padding).
- Cart badge with 10+ items and out-of-stock products (`inStock: false`) display correctly.
